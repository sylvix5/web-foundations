# Reflection

Reflecting on this full-stack web development and system design journey, the most difficult concept for me was mastering JavaScript workflow and understanding the different syntax and how they work. I overcame this challenge by breaking down the codes into blocks and relating each one to a part of the html files.

Based on the feedback received on my earlier projects, I would improve my error handling granularity and input validation robustness—specifically ensuring that frontend validation schemas (using Zod) and backend controller safeguards are perfectly synchronized to provide graceful failure states rather than generic errors.

Moving forward, I will learn more FrontEnd frameworks like React to sharpen my skills and build larger interfaces from reusable components. I will also keep practising the basics of JavaScript from web3 schools to understand the concepts better.
